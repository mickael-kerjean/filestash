## Прокрутка исходника и превью

Прокрутите любую из панелей к разделу «Длинный блок кода». Во второй панели появится тот же раздел. Измените ширину редактора и сравните, как переносы строк меняют высоту исходника.

{% note tip "Если превью нужно больше места" %}

Разделитель можно перетащить влево. С клавиатуры выберите его клавишей Tab и измените положение стрелками. В узком окне панели располагаются одна над другой.

{% endnote %}

## Длинный блок кода

Слева в исходнике видны строки и ограда блока кода. Справа в превью отображается только содержимое.

```sh
report_file="report.md"

{
  printf '# Отчёт по документации\n\n'

  printf '## Проверка файлов\n\n'
  for file in ./*.md; do
    [ -f "$file" ] || continue
    lines=$(wc -l < "$file")
    printf -- '- %s: %s строк\n' "$file" "$lines"
  done

  printf '\n## Проверка оформления\n\n'
  printf -- '- [ ] Заголовки соответствуют содержимому\n'
  printf -- '- [ ] Ссылки ведут к нужным разделам\n'
  printf -- '- [ ] Примечания видны в обеих темах\n'
  printf -- '- [ ] Примеры помещаются на узком экране\n'

  printf '\n## Следующий шаг\n\n'
  printf 'Откройте отчёт в редакторе Filestash.\n'
} > "$report_file"
```
