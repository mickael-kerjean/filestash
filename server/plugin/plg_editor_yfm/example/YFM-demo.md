# YFM в Filestash

Измените этот абзац слева. Превью обновится, а кнопка сохранения запишет исходный Markdown.

Переключите вкладку и раскройте блок ниже.

{% endnote %}

  ```sh
  printf 'Привет, YFM!\n'
  ```

- Windows

  ```powershell
  Write-Output 'Привет, YFM!'
  ```
